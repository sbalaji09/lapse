# Track B B5 Implementation Plan

> Execute with subagent-driven-development.
> Steps use `- [ ]` checkboxes.

**Goal:** Add the code-only B5 voice-transcript seam and reusable appeal packet without generating an audio asset or changing Track A code.

**Architecture:** Voice transcripts enter through a tiny adapter and continue through the existing `handle_reply` parser, with recording provenance merged into each resulting `patient_reply` fact. The PDF module gains one shared evidence-document renderer used by both the existing attestation and the new appeal packet; FastAPI exposes the appeal packet without changing shared models.

**Tech Stack:** Python 3.11+, Pydantic, FastAPI, SQLite, reportlab, pytest.

## Mission Contract

- Outcome: B5 code paths are implemented and runnable locally; future AWS Connect/Nova Sonic input can call the same voice adapter.
- Acceptance: a Spanish voice transcript resolves Rosa through the existing parser and records voice provenance; an appeal PDF is a valid PDF titled `Evidence for appeal` and shows a response deadline exactly 30 days after termination; existing attestation behavior and the full Python suite remain green.
- Non-goals: no audio generation, no OpenAI TTS call, no AWS resources or Bedrock/Strands/Connect code, no frontend audio player without an asset, no Track A model/data/rule/pipeline changes.
- Footprint: `engine/loop/inbound.py`, new `engine/loop/voice.py`, `engine/loop/pdf.py`, `api/main.py`, new Track B tests under `tests/`.

## Global Constraints

- Synthetic data only. No PHI.
- Never tell a patient they are or aren't eligible.
- Never state a clinical conclusion; the clinician attests.
- Never show a claim without a clickable source span.
- Never ask a patient something we could answer from data we have.
- Local mode stays first-class.
- The models in `engine/models.py`, the API table and the fact registry do not change.
- No code path exists only in AWS.
- The transcript goes through the same reply handler as email, stored as a `patient_reply` fact with the recording reference in `source_ref`.
- Reuse `pdf.py`; do not fork it.
- The appeal response deadline is 30 days after the termination date.
- Do not generate or commit `demo/voice_rosa.mp3`.

def handle_voice_transcript(case_id, transcript, recording_ref=None, message_id=None):
    ref = {"channel": "voice"}
    if recording_ref:
        ref["recording_ref"] = recording_ref
    return handle_reply(case_id, transcript, message_id or f"voice-{case_id}", source_ref=ref)

def case_appeal_pdf(id: str, termination_date: date):
